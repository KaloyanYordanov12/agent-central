# Asset Licenses

This document tracks every external pixel art asset pack used in Agent Central.
Each entry includes the source, author, license, and any required attribution.

## Packs Installed

### 2D Sidescroller Office Tileset
- **Author:** rixitic
- **Source:** https://rixitic.itch.io/2d-sidescroller-office-tileset
- **License:** Paid ($1 USD). Commercial use permitted per itch.io paid asset terms.
- **Installed at:** `agent_central/static/assets/tilesets/rixitic-sidescroller-office/`
- **Contents:** 3 sheets of 16×16 tiles (architecture, objects, elevator animation), Aseprite + Paint.NET sources, Tiled (.tmx) and LDtk (.ldtk) project files, example scene flattened PNG.
- **Style:** Side-view (cross-section), modern corporate office, clean professional palette.
- **Role:** Primary asset pack for Phase 1 office composition (Step C onward).

### Pixel Office Asset Pack
- **Author:** 2dPig
- **Source:** https://2dpig.itch.io/pixel-office
- **License:** Creative Commons CC0 1.0 Universal (public domain dedication)
- **Attribution:** Not required. Appreciated per author's note.
- **Installed at:** `agent_central/static/assets/tilesets/2dpig-pixel-office/`
- **Contents:** 5 human characters (front-view, static), 2 animals (cat + dog), office furniture, elevator doors, windows, sky background, floor strips. PNG + Aseprite source files. Sample scenes included.
- **Style:** Side-view (cross-section / front-facing), modern office, clean pixel art with warm + blue accents.
- **Role:** Initially Phase 1 primary; superseded by rixitic for office structure. Kept installed as potential source for character sprites if needed later.
